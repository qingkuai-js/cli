# QingKuai + Vite

This template scaffolds a QingKuai application powered by the `@qingkuai/cli` toolchain (vite under the hood). Check out the [QingKuai docs](https://qingkuai.dev) to learn more.

## Scripts

- `npm run dev` — start the vite dev server with HMR
- `npm run build` — build for production
- `npm run preview` — preview the production build
- `npm run check` — perform syntax or type checking on sources
- `npm run format` — format sources

Learn more about IDE Support for QingKuai in the [QingKuai Language Features Guide](https://qingkuai.dev/misc/language-features.html).
